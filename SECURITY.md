# Security policy

HISPANIA is pre-1.0; no contract is Public Stable. Security support and release decisions apply to the currently maintained development distribution and are determined by the repository owner.

Report a suspected vulnerability privately to the repository owner through an already established private channel. Do not open a public issue containing an exploit, secret or sensitive installation information. A public reporting address/program has not been designated; none is invented here.

Provide affected commit/distribution, local reproduction, expected/actual behavior and impact without real credentials. The owner triages severity and reachability, fixes with regression evidence, assesses compatibility, and coordinates release notes/disclosure. See `docs/security/SECURITY-OPERATIONS.md` for internal handling and `docs/security/THREAT-MODEL.md` for boundaries and limitations.
