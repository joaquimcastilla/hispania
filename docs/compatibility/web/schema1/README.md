# Web Schema 1 corpus

Independent Phase 20 frozen descriptor corpus. Four exact UTF-8 files with SHA-256 and explicit current-reader outcomes: valid accepted; future, reserved-route and script rejected. Tests compare bytes before parsing. Package signatures are independently tested with ephemeral TEST ONLY keys; no private key belongs in this corpus. Existing Phase 15/16 corpora are unchanged. Any new schema gets a new directory; do not rewrite these files to make a reader pass.
