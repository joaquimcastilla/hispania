## Estado y ámbito

Sistema futuro, fuera del alcance actual. El roadmap lo sitúa después del media server básico: Phase 21 aborda Preservation Knowledge Graph y Phase 22 Distributed Content Network.

Si existe, dependerá de Media; Media nunca dependerá de él. No debe introducir anticipadamente requisitos en Media. Preservation se estudiará entonces y no forma parte actualmente de Media.

## Límites

No hay diseño aceptado para este ámbito. Este contexto no define protocolos, manifests, blockchain, DHT, torrents, moderación ni arquitectura distribuida. No modifica Media, Kernel o contratos actuales sin una tarea futura autorizada y las ADR necesarias.
