# Clients

## Lectura obligatoria

- `CODEX.md`, `PROJECT_CONTEXT.md`, `docs/ARCHITECTURE.md` y `docs/ROADMAP.md`.
- La documentación de la API pública y del cliente concreto cuando existan.

## Estado y ámbito

Fase de roadmap: Phase 18 — Additional Clients. Tizen, Android, Android TV, desktop y otros son clientes previstos; el cliente web se sitúa antes, en Phase 5. No hay proyectos ni diseños de estos clientes.

## Límites

No crea clientes, SDKs, plataformas ni dependencias. Todos los clientes deben usar la API pública y no adquirir privilegios arquitectónicos ni lógica de negocio crítica.
